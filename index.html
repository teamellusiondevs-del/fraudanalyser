Implementation Guide - Quick Setup

Get Started in 3 Simple Steps :

Designed for non-technical users - Complete setup in under 60 seconds

1

Download Extension

Visit the official SafeShield portal and click "Add to Chrome". For SIH demonstration, a ZIP archive is provided. Production version will be available directly via Chrome Web Store with one-click installation.

safeshield-extension.zip - ⬇️ Ready to Install
2

Enable in Browser

Navigate to chrome://extensions, enable Developer Mode toggle, click "Load Unpacked" and select the extracted extension folder. The SafeShield icon 🛡️ will appear in your toolbar immediately.

Developer Mode: ON ✅ → Load Unpacked → Select Folder → Installed !
3

Pin & Activate

Click the extensions menu (🧩) in your toolbar, pin SafeShield for quick access. Protection activates automatically across all websites. No manual configuration required. Users can disable anytime via extension settings.

How to Activate Extension - 3 Easy Steps

1
Download Extension (SIH Demo ke liye)
Hamari website pe Add to Chrome button pe click karo. Abhi ke liye zip file download hogi safeshield-extension.zip. Isko unzip karo. Final product me jab Chrome Web Store pe publish hoga to direct 1-click install hoga, zip ki zarurat nahi padegi. Judge ko ye demo dikhana hai.
2
Go to chrome://extensions (Important Step)
Chrome ke address bar me ye likho: chrome://extensions aur Enter dabao. Upar right side me Developer Mode ka toggle dikhega, usko ON karo. Fir Load Unpacked button pe click karo aur jo folder unzip kiya tha usko select karo. Extension add ho jayega, toolbar me 🛡️ icon aa jayega.
chrome://extensions → Developer Mode: ON → Load Unpacked → Select Folder
3
Pin karo - Auto Active! 🎉 - Ab kaam ho gaya
Toolbar me puzzle icon 🧩 pe click karo → SafeShield ke saamne Pin 📌 icon pe click karo. Ab se har website pe extension khud se auto-active hai. Tumhe har baar ON nahi karna. Flipkart kholo to adult products auto-blur, http wali fake internship site kholo to full page block. Agar band karna ho to extension icon pe click karke toggle OFF kar do - user ke paas full control hai, koi force nahi. Yehi hamara USP hai.
